# Интеграционные сценарии

## 1. Успешное бронирование

1. Пользователь открывает публичную страницу приложения.
2. Видит доступные event types.
3. Выбирает event type.
4. Переходит на страницу бронирования.
5. Выбирает дату с доступными слотами.
6. Выбирает свободный временной слот.
7. Заполняет имя и email.
8. Отправляет форму.
9. Видит успешное подтверждение бронирования.

## 2. Повторное бронирование занятого слота

1. Пользователь выбирает event type и свободный слот.
2. Создаёт бронирование.
3. Повторно пытается забронировать тот же event type и тот же слот.
4. Видит понятную ошибку: слот уже занят или больше недоступен.
5. Для повторной попытки не отображается успешное подтверждение.
